# 메모 (맥 + 갤럭시 실시간 동기화)

한 번 만들어 두면 맥과 갤럭시에서 같은 메모가 실시간(1초 안팎)으로 맞춰지는 메모 앱. 무료.

## 1. Supabase 준비 (처음 한 번)
1. https://supabase.com/dashboard → New project (무료 플랜, 지역은 Seoul)
2. 왼쪽 **SQL Editor** → `schema.sql` 내용 전체 붙여넣기 → Run
3. **Authentication → Sign In / Providers → Email** 에서 "Confirm email" 끄기 (혼자 쓰니 메일 확인 불필요)
4. **Project Settings → API** 에서 `Project URL` 과 `anon public` 키를 복사해 `config.js` 에 넣기

> 무료 플랜은 7일 동안 아무도 안 쓰면 일시정지된다. 매일 쓰면 상관없고, 멈추면 대시보드에서 Restore 한 번.

## 2. 인터넷에 올리기
폰에서 앱처럼 설치하려면 https 주소가 필요하다. 이 폴더를 그대로 아무 정적 호스팅에 올리면 됨
(GitHub Pages / Cloudflare Pages / Netlify — 모두 무료).

## 3. 설치
- **갤럭시**: 크롬(또는 삼성 인터넷)으로 주소 열기 → 메뉴 → **홈 화면에 추가 / 앱 설치**
- **맥**: Safari로 주소 열기 → 파일 메뉴 → **Dock에 추가** (크롬이면 주소창 오른쪽 설치 아이콘)
- 두 기기에서 같은 이메일·비밀번호로 로그인 (처음 한 번은 "새 계정 만들기")

## 기능
폴더 · 고정(📌) · 검색 · 제목/굵게/기울임/밑줄/취소선 · 목록 · 체크리스트 · 표 · 최근 삭제된 항목(30일 보관 후 비움) · 다크 모드 · 오프라인에서 쓰고 연결되면 자동 업로드

## 아직 없는 것
사진·첨부파일, 손글씨, 문서 스캔, 메모 잠금, 공유/공동 편집, 같은 메모를 두 기기에서 *동시에* 칠 때 글자 단위 합치기(지금은 나중에 저장한 쪽이 이김).
